# FirstDemo-WPFwithHalcon
## **C# Halcon 空滤器视觉检测系统**

## **基于 WPF 的工业化视觉检测与数据交互方案**

***\*项目定位\****：
本系统是一套基于 Halcon 视觉算法与 C# WPF 框架开发的工业视觉检测上位机原型系统，旨在模拟真实产线双工位检测与 PLC 数据交互场景，通过单台相机两次不同曝光拍照实现低曝光检测条码，高曝光检测滤芯以及钢圈有无。

 

### **核心功能模块**

 

1. 单工位双曝光协同检测：单相机分时拍摄模式，低曝光完成条码读取，高曝光实现滤芯与钢圈缺陷判断。。
2. Halcon 算法集成（条码识别与定位、钢圈/滤芯有无检测）
3. 工业数据交互（支持与 HslCommunication 虚拟 PLC 通讯心跳、信号触发与结果回写）。
4. 多模式运行（单张调试模式、批量循环模式、自动触发模式）。
5. 实时看板与日志（检测结果实时显示、操作日志记录与历史图片查找）。

### **技术栈与架构说明**

### ***\*开发环境\******：**

### **操作系统：Windows 10 / 11 专业版**

### **开发工具：Visual Studio 2022, Halcon 23.05 Progress**

***\*目标框架：.NET\**** ***\*8\*******\*.0 (WPF)\****

***\*核心技术栈\****：

视觉算法：Halcon（基于模板匹配、条码识别、Blob 分析、区域提取）

上位机 UI：WPF / XAML / MaterialDesignInXAML 开源 UI 库

工业通讯：HslCommunication（C# 开源 PLC 通讯库，Siemens S7 协议）

 

***\*架构设计\****：

UI与算法分离：将 Halcon 核心算法封装为独立的 HalconProcessor 类，与 UI 界面完全解耦。

多线程处理：后台任务与相机模拟使用 Task.Run 异步执行，确保 UI 界面流畅不卡顿。

------



 

 

 

***\*项目总结\****

本系统通过单相机工位两次拍照视觉检测的架构，展示了将 Halcon 算法集成至 C# WPF 工业软件中的完整能力。系统成功模拟了多相机协作、PLC 信号握手、视觉结果回传等典型产线场景。
